# Plants vs. Zombies Builder 1.0

An offline-capable HTML5 builder for custom plants, zombies, lawns, levels and campaigns.

Play: https://berrypvz.github.io/PvZBuild/

Create your own content with 210 abilities, per-state GIF/PNG animations and MP3/WAV sounds, custom lawnmowers, map grid alignment, NPC dialogue, weather and base64 level-pack imports/exports. The workshop starts empty.

Download index.html to run offline. Browser saves are local to each device and website origin; export packs to transfer or back up projects.

Fan-made project. Plants vs. Zombies belongs to EA / PopCap.
